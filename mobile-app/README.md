# HEALTHY + BRAIN 🧬🧠
> **Soberanía Biológica & Longevidad Gamificada**

`healthy + brain` es una plataforma descentralizada de gestión biográfica que transforma tus métricas de salud en activos digitales. Utilizando el motor **Bio-ID Engine**, la aplicación permite a los usuarios tomar el mando de su longevidad a través de la transparencia de datos y una economía basada en el token **NTK**.

## 🌟 Pilares del Proyecto

- **Soberanía de Datos (Bio-ID):** Tus biometrías se procesan localmente. El usuario decide qué pruebas de conocimiento (ZKP) comparte con la red para el ranking comunitario.
- **Economía Neuro-Token (NTK):** Recompensas dinámicas por mantener una racha de salud, sincronizar dispositivos externos y participar en retos biológicos.
- **Coach IA Contextual:** Análisis en tiempo real de HRV y pasos para ofrecer recomendaciones personalizadas de "Dopamine Reset" y "Vagal Reset".
- **Atlas Orgánico:** Visualización 3D interactiva del estado sistémico del usuario basada en biometrías reales.

## 🛠️ Stack Tecnológico

- **Frontend:** React Native + Expo (SDK 51+)
- **Navigation:** Expo Router (File-based routing)
- **Styling:** Vanilla StyleSheet + Glassmorphism Design System
- **Backend:** Firebase Firestore + Auth (Anonymous & Email)
- **Biometrics:** Expo Sensors + Native Health API Integration
- **Animations:** React Native Animated + Linear Gradients

## 🚀 Instalación y Desarrollo

1. **Clonar el repositorio:**
   ```bash
   git clone <repo-url>
   cd mobile-app
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Configurar Firebase:**
   - Añade tu `google-services.json` (Android) y `GoogleService-Info.plist` (iOS) en la carpeta raíz.
   - Configura las variables de entorno para la configuración web en `constants/FirebaseConfig.ts`.

4. **Correr localmente:**
   ```bash
   npx expo start
   ```
