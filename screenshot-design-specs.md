## 📱 Phone Frame Mockup Specs

### Recommended Frame Style:
- **iPhone 15 Pro** dark titanium frame
- **Floating notch** style
- **Rounded corners** matching actual device

### Overlay Settings:
- **Screenshot size**: 1080x1920
- **Frame padding**: 0 (full bleed)
- **Corner radius**: 55px (iPhone style)

---

## 🎯 Key Visual Principles

1. **Dark Theme Dominant** - Most screens on #0A0A0A background
2. **Neon Accents** - Use green, blue, orange for highlights
3. **Data Visualization** - Show numbers prominently (85, 78, 520)
4. **Motion Feel** - Use arrows and progress indicators
5. **Trust Signals** - Show checkmarks, badges, verified icons
6. **Human Element** - Include user stats, names placeholders
7. **Action Oriented** - Include buttons like [+50 NTK], [SAVE]
